## 🚀 Overview

This project demonstrates how to use Google Sheets as a completely free, zero-maintenance Headless CMS. By utilizing the Opensheet API, it fetches public spreadsheet data directly into the client-side JavaScript and dynamically renders it as a clean HTML table.

This architecture is perfect for:
- **Rapid Prototyping**: Build data-driven UI components without setting up a database.
- **Zero-Backend Apps**: Host everything on GitHub Pages.
- **Non-Technical Updates**: Allow stakeholders to update the frontend by simply editing a Google Sheet.

## ✨ Features

- **Real-Time Data Fetching**: Updates immediately when the Google Sheet is updated.
- **Responsive HTML Table**: Mobile-friendly data display out of the box.
- **Zero Dependencies**: Built with pure HTML, CSS, and Vanilla JavaScript.
- **No API Keys Needed**: Relies on the public sharing link of the Google Sheet.

## 🛠️ How to Use

1. **Prepare the Data**: Create a Google Sheet and make it **Publicly accessible** ("Anyone with the link can view").
2. **Configure**: Open `index.html` and replace the placeholder Google Sheet URL or ID with your own.
3. **Deploy**: Host the files statically on GitHub Pages, Vercel, or Netlify.
